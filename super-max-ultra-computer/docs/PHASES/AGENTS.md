# AGENTS 안내: `docs/PHASES`

이 파일은 에이전트(자동화 도구, 작업 관리자 등)가 `docs/PHASES` 폴더를 인식하고 참조할 수 있도록 간단한 안내를 제공합니다.

요약:
- `docs/PHASES` 폴더에는 프로젝트 개발을 7개의 Phase로 나눈 요구사항과 각 Phase의 완료 기준이 정리되어 있습니다.
- 에이전트는 이 문서를 참고하여 구현 우선순위, 테스트 케이스, 배포 단계별 체크리스트를 자동 생성하거나 작업 티켓을 생성할 수 있습니다.

사용 예시:
- 구현 담당자는 `PHASE1 ~ 7.md`에서 각 Phase의 완료 기준을 확인하여 작업 분해 및 스프린트 계획 수립에 활용합니다.
- CI/자동화 에이전트는 각 Phase의 완료 체크리스트를 기준으로 자동 검증 스크립트(테스트, 배포 체크)를 연결할 수 있습니다.

권장 작업 흐름:
- Phase 문서 확인 → 작업 항목 생성 → 개발/테스트 → 체크리스트 기반 승인 → 다음 Phase 진행
