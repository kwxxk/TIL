# 카페 판매 실습 데이터 출처

## 생성 정보

| 항목 | 내용 |
| --- | --- |
| 파일명 | `cafe_sales.csv` |
| 생성 방식 | `실습2_NumPy와Pandas_정답.ipynb`에서 NumPy 난수로 생성 |
| 난수 기준 | `np.random.seed(42)` |
| 데이터 크기 | 200행 × 5열 |
| 컬럼 | 지역, 메뉴, 단가, 수량, 매출 |

## 사용 안내

이 파일은 노트북에서 난수로 생성한 실습용 가상 데이터입니다. 노트북을 위에서부터 실행하면 같은 기준으로 파일을 다시 저장하므로, 기존 파일은 덮어써도 됩니다.
